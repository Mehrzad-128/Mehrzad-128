# 🤖 How I Use AI in Development

AI is increasingly part of my development workflow, but I treat it as an **engineering tool rather than a substitute for understanding the code**.

I use AI coding agents such as **Claude and Cursor** for:

* Understanding unfamiliar codebases
* Exploring existing architectures
* Implementing features
* Debugging
* Refactoring
* Generating and improving tests
* Researching unfamiliar technologies
* Working across frontend and backend code
* Reviewing implementation approaches

I've also worked with **Model Context Protocol (MCP)** and implemented/used **Angular MCP** to extend AI-assisted development workflows.

I'm interested in the intersection of software engineering and increasingly capable developer tools, particularly where they can improve development speed without sacrificing understanding, maintainability, or code quality.
